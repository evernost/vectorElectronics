The purpose of this article is to describe an attempt to solve electronic circuits with non-linear devices like diodes, bipolar transistors, MOSFETs, etc.\\

A common approach is to set the circuit at some operating point and wiggle around it with the input signal.\\
For small variations, even the most non-linear device can be approximated by a linear model.
The \textit{Small Signal Analysis}, as it is called, is a classical framework for that.\\

However, some cases are trickier and require the device to operate way beyond the small signal hypothesis assumption. 
The class AB amplifier is one example: each transistor in the push/pull pair goes from cutoff to linear region as the input changes.\\
One could try to use a detailed model for the transistor (exponential curve), however:
\begin{itemize}
    \item the equations usually have no closed-form expression (equations combining $\exp()$ and polynomials) 
    \item it doesn't give much insight on \textit{how} the thing works. 
\end{itemize}

\subsubsection*{An extension of the Small Signal Analysis}
In the following, we will consider that the non-linear device has a characteristic curve that can be modelled as a \textit{piecewise linear function}. From that point on, we will investigate where this leads us.

\paragraph{Derivation}

Assuming that $I_C = f_S(V_{BE})$ for the NPN and $I_C = f_D(V_{EB})$ for the PNP we get the following:

$$
\left\{
    \begin{array}{ll}
        I_S = f_S \left(v_{IN} - v_{OUT} + \dfrac{v_B}{2} - R_E I_S \right) \\
        I_D = f_D \left(-(v_{OUT} - v_{IN}) + \dfrac{v_B}{2} - R_E I_D \right) \\
        V_{OUT} = R_L(I_S-I_D)
    \end{array}
\right.
$$\\

% With a linear assumption, it becomes:
% $$
% \left\{
%     \begin{array}{ll}
%         I_S = \dfrac{a_S}{1+R_E a_S}(V_{IN}-V_{OUT}+\dfrac{V_B}{2}) + \dfrac{b_S}{1+R_E a_S} \\
%         I_D = \dfrac{a_D}{1+R_E a_D}(-(V_{IN}-V_{OUT})+\dfrac{V_B}{2}) + \dfrac{b_D}{1+R_E a_D} \\
%         V_{OUT} = R_L(I_S-I_D)
%     \end{array}
% \right.
% $$\\

This time, the equations are trickier: the key variables $I_S$, $I_D$ and $V_{OUT}$ are all intertwined.
We cannot carry out the analysis the way we did in the previous sections.\\

Let's try to analyse the system as 2 independant subsystems.

\subsection*{Class AB subsystem: the current source}
If we split the full schematic in half and set the input voltage to a constant, we can simplify the current source of the circuit to a much simpler block:\\

	\node[eground2] at (2, 2.73){};

Using the usual voltage and currents laws gives the following source current:
$$
I_S = f_S \left(-\Delta V + \dfrac{v_B}{2} - R_E I_S \right) \\
$$

Under a linear model assumption $f_S(V) = aV+b$, we can write that:
$$
I_S = a \left(-\Delta V + \dfrac{v_B}{2} - R_E I_S \right) + b \\
$$

Finally, after a bit of algebra:
\fbox{$I_S = -\dfrac{1}{R_E}\dfrac{a R_E}{1+a R_E}\Delta V + \dfrac{a \frac{V_B}{2} + b}{1 + a R_E}$}
